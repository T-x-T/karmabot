Encourage positive, funny and helpful content in your community using TxT's Karmabot.

TxT's Karmabot is a Discord bot which adds a karma system to your Discord server, similar to Reddit.
Voting is done through reactions, bot commands and this website are used to view lots of stats.

Get Txt's Karmabot

Step 1:

Invite me

Step 2:

Set default vote emojis

/config server use_default_upvote_emoji:True
/config server use_default_downvote_emoji:True

Step 3:

Get to voting!

Also don't forget to vote for this bot on top.gg ;)
